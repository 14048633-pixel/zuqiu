# 数据格式清单 v1.0 — 防"提取失败"复发的依据
> 本清单收录系统已支持的所有数据格式。遇到清单外的格式时，必须走"新格式处理流程"（见文末），禁止直接编造或跳过。

## 一、盘口格式（data_extractor 支持）

### 1. 独赢（胜平负赔率）
| 格式 | 示例 | 说明 |
|------|------|------|
| 两列 | `独赢 - 1.77 4.50` | 主+客，自动补合理平局赔率 |
| 三列 | `独赢 - 2.79 3.20 2.21` | 主+平+客 |
| 带主客标记 | `独赢 - 主2.92 客2.16` | 主+客 |

### 2. 让球盘口
| 格式 | 示例 | 说明 |
|------|------|------|
| 无@两数字 | `让球 +0/0.5 1.90 1.92` | 盘口+主赔+客赔 |
| 带@ | `让球 +0/0.5 @1.75 -0/0.5 @2.07` | 主盘口@赔率+客盘口@赔率 |
| 平手盘 | `让球 0 2.19 1.72` | 无符号0 |
| 中文平手 | `平手` / `平手 @1.90` | =0 |

### 3. 大小球
| 格式 | 示例 |
|------|------|
| 单盘口 | `大小球 2.5 大1.99 小1.81` |
| 复合盘口 | `大小球 2/2.5 大1.89 小1.97` |

### 4. 让球细分表
| 格式 | 示例 |
|------|------|
| 无@ | `+0.5 1.68 -0.5 2.16` |
| 带@ | `+0.5 @1.58 -0.5 @2.31` |
| 带表头 | `主队盘口 主队赔率 客队盘口 客队赔率` |

### 5. 大小球细分表
| 格式 | 示例 |
|------|------|
| 单盘口 | `大2.5 1.74 小2.5 2.13` |
| 复合盘口 | `大2/2.5 1.76 小2/2.5 2.11` |

## 二、情报格式（feature_extractor / λ计算 支持）

### 1. 场均进球/失球（λ主依据）
| 格式 | 示例 | 说明 |
|------|------|------|
| 紧凑 | `场均进1.3失0.7` | 一场一个 |
| 独立字段 | `场均进球1.3球场均失球0.7球` | 分开写 |
| 含空格 | `场均进球 1.3 球 场均失球 0.7 球` | |

### 2. 累计数据（交叉验证用）
| 格式 | 示例 |
|------|------|
| 进失球 | `总进球13球总失球7球` |
| 近N场 | `近10场2胜6平2负` |

### 3. 射门/射正/转化率
| 格式 | 示例 |
|------|------|
| 场均射门 | `场均射门15.2次场均射正5.6次` |
| 转化率 | `射正转化率17.8%` |
| 总射门 | `总射门150次总射正56次` |

## 三、情报段落标题（_split_sections 识别）
`近10场战绩` / `近期状态` / `历史交锋` / `伤病停赛` / `战意` / `优先级` / `联赛现状` / `场地` / `天气` / `战术` / `总结` / `细节`
> 可带冒号（如"近10场战绩:"）或不带；带句号结尾的完整句不算标题。

## 新格式处理流程（遇到清单外格式时必须执行）

1. **停下问用户**：确认新格式的具体写法和字段含义（禁止猜测）
2. **确认后加正则/逻辑**：在 `data_extractor.py` 或 `feature_extractor.py` 加支持
3. **写回归断言**：把新格式加到 `regression_test.py`，确保以后不退化
4. **跑回归**：`python regression_test.py` 必须全绿
5. **更新本清单**：把新格式加入对应表格
6. **更新 SESSION_STATE.md**：记录新增格式

> 任何一步缺失 = 流程不完整，禁止继续。
