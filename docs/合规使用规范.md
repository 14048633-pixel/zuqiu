# 合规使用规范（重要）

> 版本 v1.0 · 2026-08-14 · 本文件为系统强制合规条款，任何使用本系统者必须阅读

## 一、系统定位
- 本系统（含 auto_sop.py / prediction_v2 / 各类模型与规则引擎）**仅作赛事数据统计与数学分析工具**
- 输出内容（分析记录、EV、best_bet、串关建议等）**均为统计计算结果，不构成任何投注建议**
- 系统不连接、不代操作任何博彩账户；所有投注行为由使用者自行决定并承担责任

## 二、风险提示（每次运行前必读）
- 体育赛事结果天然随机，任何模型**无法稳定盈利**，不存在"必胜策略"
- 历史回测收益（如 +240% ROI）为**样本内结果**，不保证未来复现；存在过拟合与市场变化风险
- 建议：只用可承受损失的闲钱，单日总投注 ≤ 本金 15%，单场 ≤ 本金 5%，串关 ≤ 本金 2%
- **禁止大额投注、借贷投注、追偿式加注**

## 三、禁止事项
- 禁止未成年人使用本系统
- 禁止将本系统用于违法赌博、非法博彩、洗钱或任何违法违规活动
- 禁止在禁止博彩的地区/平台使用
- 禁止将系统输出包装为"稳赚""包赢"等误导性承诺

## 四、合法观赛数据分析边界
- 本系统鼓励的用途：赛事数据研究、概率建模、学术/业余分析、观赛参考
- 网络博彩与合法观赛数据分析的边界以当地法律为准；使用者须自行确认所在司法辖区的合法性
