## 五、平局预警规则升级（市场为主信号）
1. **平赔 ≤3.1 → 防平高危**（实际 ≥33%）；3.1~3.7 → 防平提醒（28~30%）
2. **联赛修正**：西甲/西乙平赔 2.8~3.1 平局率最高（37.5%/33.2%）→ 优先防平；德甲/德乙平局率天然低，平赔 3.5+ 才算高危
3. **次级联赛（西乙/英冠/德乙）整体平局率 >27%** → 出让球深盘自动防平
4. **市场隐含平局概率 ≥31%** 的场次，1X2 不追强队，让球盘选 +0.5 受让侧
5. 与账本规律合并：平赔 3.0~3.8 + 高危联赛 + 让球深盘 = 强防平信号
