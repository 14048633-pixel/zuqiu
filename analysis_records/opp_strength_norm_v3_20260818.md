## 二、融合公式
```
dom_est = (dom场均 / 国内联赛场均[主客分列]) × 国内联赛coef，收缩K=6向coef
final   = (w_euro × euro_v2 + w_dom × dom_est) / (w_euro + w_dom)，w=min(n,20)
国内日期衰减: age<400天=1.0 / <730天=0.6 / ≥730天=0.2；近期<5场判陈旧弃用
```
