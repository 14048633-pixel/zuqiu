# 足球竞猜策略 v2.0

## 一、大小球策略

### 1.1 核心逻辑
```
推荐公式：
当 盘口 < 联赛场均进球 × 0.85 时 → 推大球
当 盘口 > 联赛场均进球 × 1.15 时 → 推小球
```

### 1.2 联赛进球数据

| 联赛 | 场均进球 | 大2.5率 | 大3.5率 | 推荐策略 |
|------|----------|---------|---------|----------|
| 中超 | 2.6球 | 55% | 30% | 偏小球 |
| MLS | 3.0球 | 60% | 40% | 均衡 |
| MLS Next Pro | 3.42球 | 66% | 45% | 偏大球 |
| 澳洲NPL | 3.76球 | 77% | 56% | 大球为主 |
| 澳洲U23 | 4.01球 | 76% | 56% | 大球为主 |
| 友谊赛 | 2.8球 | 52% | 32% | 偏小球 |

### 1.3 信心等级调整

| 条件 | 信心调整 |
|------|----------|
| 盘口比联赛场均低0.5球以上 | +1星 |
| 盘口比联赛场均高0.5球以上 | +1星 |
| 赔率水位<1.85 | +1星 |
| 赔率水位>2.05 | -1星 |
| 友谊赛 | -1星 |

## 二、让球策略

### 2.1 核心逻辑
```
1. 计算赔率隐含概率
2. 对比模型预测概率
3. 当 模型概率 > 赔率隐含概率 + 5% 时 → 有价值
```

### 2.2 让球盘口分析

| 盘口 | 让球方需净胜 | 覆盖概率 |
|------|--------------|----------|
| 平手/平半 | 赢球即可 | 90% |
| 半球 | 净胜1球 | 70% |
| 半/一 | 净胜1球全赢 | 60% |
| 一球 | 净胜2球全赢 | 50% |
| 深盘(>1) | 净胜更多 | 40% |

### 2.3 排除条件

```python
if 比赛类型 == "友谊赛":
    不推荐让球
if 让球盘口 > 1.0:
    降低1星信心
```

## 三、信心等级对齐

### 3.1 期望值计算
```
期望值 = 模型概率 - 赔率隐含概率
```

### 3.2 信心等级映射

| 期望值 | 信心等级 |
|--------|----------|
| >15% | ⭐⭐⭐⭐⭐ (5星) |
| >10% | ⭐⭐⭐⭐ (4星) |
| >5% | ⭐⭐⭐ (3星) |
| >0% | ⭐⭐ (2星) |
| ≤0% | ⭐ (1星) |

### 3.3 联赛类型调整

| 联赛类型 | 调整 |
|----------|------|
| 正式联赛 | 不调整 |
| 友谊赛 | -1星 |
| 青年联赛 | 不调整 |

## 四、凯利指数

### 4.1 计算公式
```
凯利 = (胜率 × (赔率-1) - (1-胜率)) / (赔率-1)
凯利 = 凯利 × 保守系数(0.25)
```

### 4.2 使用规则

| 凯利值 | 建议 |
|--------|------|
| >10% | 可下注 |
| 5%-10% | 小注 |
| <5% | 观望 |

## 五、实战组合

### 5.1 稳健型
- **目标**：大2.5 @1.85
- **条件**：联赛场均≥3.0球，盘口≤2.5
- **预期胜率**：65%

### 5.2 进取型
- **目标**：大3/3.5 @1.90
- **条件**：联赛场均≥3.5球，盘口≤3.0
- **预期胜率**：58%

### 5.3 保守型
- **目标**：小2.5 @1.90
- **条件**：联赛场均≤2.5球，盘口≥2.5
- **预期胜率**：60%

## 六、快速检查表

```
□ 查联赛场均进球
□ 查盘口
□ 计算：盘口/联赛场均
□ 比值<0.85 → 大球
□ 比值>1.15 → 小球
□ 检查水位（<1.85加1星，>2.05减1星）
□ 检查联赛类型（友谊赛减1星）
□ 确定信心等级
□ 计算凯利指数
□ 做出最终决定
```
